# terra-three

This project is made for learning purposes only. It uses Godot version 4.7, and uses assets froma  youtube video titled: The new ultimate introduction to Godot.

The game is a 2D platformater shooter, with mechanics involving enemies, level restart and lighting. I used shaders, tweens, lighting in this project for the first time.

How to play:
- download project files and open in Godot. OR
- Open within browser using link: https://dzsi-dzimi.itch.io/2d-shooter-game
