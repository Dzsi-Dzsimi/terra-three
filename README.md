# terra-three

This project is made for learning purposes only. It uses Godot version 4.7, and uses assets from the youtube video titled: The new ultimate introduction to Godot.

The game is a 2D platformater shooter, with mechanics involving enemies, level restart and lighting. I used shaders, tweens, lighting in this project for the first time. I also used tilemaps with collisions for the graphics. The gameplay consists of the player having to shoot enemies and make it out of the level by working through its various layers. Each enemy has 3 health points and explodes upon death. If an enemy gets too close to the player, its explosion causes the player to die.

How to play:
- download project files and open in Godot. OR
- Open within browser using link: https://dzsi-dzimi.itch.io/2d-shooter-game
